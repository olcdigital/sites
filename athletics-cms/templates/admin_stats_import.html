This is the real vendor format — a school's actual PrestoSports export, not an invented shape. Nothing in the feed itself says which <team> is us; this importer figures that out from this game's Home/Away setting (set it on the Edit Game page if the preview says it couldn't tell), falling back to matching the opponent's name for a neutral-site game. "final" vs. "live" status is inferred from whether the feed contains a completed scoring marker — confirmed accurate against a real final-game export, not yet checked against a real in-progress one. Field position, team totals, and player stat lines are all mapped from the feed's own numbers onto this app's schema — see the mapping notes in app.py's _parse_stats_feed_xml if you need the exact field-by-field detail.
